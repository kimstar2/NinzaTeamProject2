# 노드 개발자 툴

Unity Editor Play 모드와 Development Build에서만 동작합니다.
노드 맵이 준비된 씬의 Game 화면에서 **Ctrl + Shift + Space + T** 네 키를 함께 누르면 열립니다.
좌우 Ctrl/Shift 모두 지원하며, 누르는 순서는 상관없습니다. 다시 누르거나 Esc/닫기로 닫습니다.

- **노드 이동**: 현재 스테이지의 열/칸/종류로 검색하고 연결 경로와 관계없이 이동합니다. 맵 진행 위치를 저장하며 노드 이벤트는 실행하지 않습니다.
- **노드 진입**: 선택한 노드로 이동하고 전투 또는 이벤트/휴식 씬 진입을 실행합니다. 전투 미리보기는 생략합니다. 전투 확인창이 이미 열려 있다면 먼저 닫으세요.
- **주사위 면 지급**: 면 이미지, 이름, 등급, 사용 직업과 스킬 이름을 함께 표시합니다. 기존 `Resources/DiceCatalog`에 등록된 미해금 스킬도 Lv.1 주사위 조각으로 배낭에 추가할 수 있습니다. 배낭에서 기존 방식으로 장착하세요. 중복 획득 가능, 배낭 용량 제한 적용.
- **검색**: 면 이름·스킬 이름·직업·등급과 한국어 노드 종류를 검색합니다. 한글 IME 입력/붙여넣기, 초성 검색(예: `ㅎㅇ`), 공백 없는 검색을 지원합니다. 검색창 입력 중 Esc는 입력을 종료하며, 다시 Esc를 누르면 창이 닫힙니다.
- 기존 게임의 MonaS10 한국어 픽셀 글꼴, PanelFrame 프레임, 남색/보라색 색상을 사용합니다. OS 글꼴에 의존하지 않습니다.
- 획득은 실제 인벤토리와 도감에 적용됩니다. 노드 위치도 실제 맵 저장에 반영됩니다.
- 창이 열린 동안 기존 EventSystem을 잠시 비활성화하고 닫거나 씬을 떠날 때 원래 상태로 복구합니다.

## 삭제 방법

Play 모드를 종료한 다음 Unity Project 창에서 **Assets/DeveloperTools 폴더를 삭제**하면 됩니다.
게임 씬/프리팹에는 개발자 툴 컴포넌트를 저장하지 않아 Missing Script가 남지 않습니다. 폴더 안의 UI 템플릿 프리팹도 함께 삭제하면 됩니다.
기존 `NodeMaker`, `NodeEvent`, `MapHud`에는 `partial` 키워드만 추가했습니다. 삭제 후에도 유효한 C# 선언이므로 그대로 두어도 됩니다.
일반 빌드에서는 이 폴더의 C# 구현 전체가 전처리 조건으로 제외됩니다.

## 수동 검증

1. 모험 시작 후 노드 씬의 Game 화면에서 단축키를 누르고, 계속 누르고 있어도 한 번만 열리는지 확인.
2. 막힌/이전 노드로 이동하고 표시와 다음 이동 가능 노드가 바뀌는지 확인. 씬 재진입 후 위치 유지 확인.
3. 전투·정예·보스·이벤트·휴식 노드 진입 확인. 전투 패배 시 진입 전 맵 위치 복원 확인.
4. 스킬 검색/반복 획득, 배낭 표시/장착, 용량 초과 및 인벤토리 없는 상태 안내 확인.
5. 툴 뒤쪽 버튼 입력 차단, 닫은 뒤 UI 입력 복구, 다른 씬에서 단축키 무반응 확인.
6. 일반 빌드에서 툴 비활성 확인. 폴더 삭제 후 재컴파일 확인.
7. 주사위 면 탭에서 이미지/등급/직업 표시, 한글 조합 입력 및 붙여넣기, 초성·공백 무시 검색, 검색 결과 없음 표시 확인.
