사용 방법
1. 01_효과음 또는 02_BGM 안의 한국어 카테고리를 선택하세요.
2. 각 폴더의 파일목록_출처.txt에서 음원 이름, 설명, 제작자, 출처와 다운로드 링크를 확인하세요.
3. OGG / MP3 / WAV 원본을 게임 엔진에 가져와 사용하세요.
   기본 플레이어에서 OGG가 열리지 않으면 OGG를 지원하는 게임 엔진이나 플레이어로 확인하세요.

선정·정리 기준
- 웹사이트에 공개된 음원을 다운로드했습니다. 새로 생성한 음원은 없습니다.
- 출처 페이지에 CC0가 명시된 자료를 골랐습니다.
- 원본 음질과 파일명을 유지했습니다. 편집·볼륨 변경·포맷 변환은 하지 않았습니다.
- BGM ZIP에 같은 곡의 여러 형식이 있으면 OGG 하나만 포함했습니다.
- Shop Theme는 일반 버전과 Radio Edit가 달라 둘 다 포함했습니다.
- Kenney 팩의 Preview.ogg는 미리듣기 모음이므로 포함하지 않았습니다.
- 분위기 설명은 제작자 설명·태그와 파일명에 따른 추천 분류입니다. 전곡 청음 평가는 하지 않았습니다.
- 다운로드 ZIP 무결성과 모든 음원의 형식·재생 시간 정보를 검사했습니다.

사용 조건
- CC0 기준 상업적 사용, 수정, 게임에 포함한 배포가 가능하며 출처 표기는 의무가 아닙니다.
- 자료별 공개 라이선스를 확인한 기록이며 제3자의 권리 관계까지 별도로 검증한 것은 아닙니다.
- 크레딧을 남기고 싶으면 각 TXT의 제작자와 출처를 이용하세요.
- Shop Theme 게시물에 제시된 크레딧 문구도 해당 TXT에 보존했습니다.
- 원본 Kenney 라이선스와 출처별 확인 기록은 03_라이선스_기록에 있습니다.
