# SkillTestScene

`Assets/Members/PSW/Scene/SkillTestScene.unity`를 단독으로 열고 Play한다.

- 오른쪽 목록의 버튼을 누르면 주사위와 턴 진행 없이 기존 SkillLogicExecutor를 실행한다.
- 현재 Members 폴더의 SkillDataSO 116개가 등록되어 있다. 한글 스킬명 또는 영문 에셋명으로 검색할 수 있다.
- 목록에 SkillDataSO.Icon을 표시하며, Target 설정에 따라 적/아군/자신을 자동 선택한다.
- 화면 아래 각 유닛의 직업 버튼을 누르면 직업과 외형·애니메이션이 함께 바뀐다. 아군/적 소속과 체력은 유지하고 상태 효과는 지운다.
- 기본은 수동 직업 선택이다. 시전자 자동 직업을 켜면 스킬에 맞춰 직업을 변경한다. 시전자 직업 버튼을 누르면 다시 수동 모드가 된다.
- 아군 3명과 적 3명으로 단일·광역 공격, 회복, 상태 효과를 확인할 수 있다.
- 체력은 1000 중 500에서 시작한다. 자폭을 포함한 피해로도 1 미만으로 떨어지지 않는다.
- 슬라이더로 스킬 배율을 1~20으로 조절한다.
- 초기화 버튼은 현재 시전을 취소하고 체력·상태·위치를 되돌린다.
- 시전 중에는 스킬 버튼을 잠근다. 20초 내 종료되지 않으면 시전을 취소하고 안내한다.

실제 전투의 에이전트, 배경, 파티클 풀과 스킬 프리팹을 사용한다. 원본 PlayerDataSO/EnemyDataSO의 런타임 체력을 변경하지 않는다.

## 새 스킬 등록

Play 모드를 종료하고 다른 씬을 연 뒤 `Tools > PSW > Rebuild Skill Test Scene`을 실행한다.
현재 SkillDataSO를 다시 검색하여 테스트 씬 전체를 재생성하므로, 이 씬을 직접 수정한 내용은 재생성 시 교체된다.

## 확인한 내용

- Unity에서 116개 스킬 순차 시전 및 종료: 실행 오류 없음.
- 모든 테스트 캐릭터에 최대 피해 적용 후 생존과 체력 초기화 확인.
- UI에서 공격·광역 회복 버튼, 이름 검색, 초기화 직접 확인.
