# 일식 / Eclipse

`Assets/Members/PSW/Particle Test Scene.unity`의 `Eclipse - 일식` 프리팹.

Play 모드에서 자동 재생하며 5.2초 연출 후 1초 간격으로 반복합니다.
선택한 오브젝트의 Inspector에서 `Preview Eclipse` 또는 `Timeline (seconds)`로
Play 모드 없이도 확인할 수 있습니다. 미리보기를 마친 뒤 `Reset Preview`를 누릅니다.

| 시간 | 연출 |
| --- | --- |
| 0.12–0.8초 | 금빛 해와 은빛 달 생성, 주변 빛가루 |
| 1.05–2.15초 | 서로 반대 궤적을 따라 중앙으로 합체 |
| 2.15–2.55초 | 검은 원반과 은빛·보랏빛 코로나 유지 |
| 2.55–3.35초 | 밝은 균열이 번지며 긴장감 축적 |
| 3.35–5.2초 | 균열 경계를 따라 33개 조각 분리, 낙하 및 잔광 소멸 |

`Playback Speed`로 전체 속도, `Repeat Delay`로 반복 간격을 조절합니다.
한 번만 실행하려면 `Loop Preview`를 해제합니다. 코드에서는 `Play()` / `Stop()`을 사용합니다.
`Play On Enable`을 해제하면 호출 시에만 실행됩니다. 루트 Transform으로 위치와 전체 크기를 조절합니다.

메시·머티리얼·네 개의 Particle System은 `Art/Eclipse.prefab`에 저장되어 있습니다.
런타임 스크립트는 DOTween으로 시간과 기존 오브젝트만 제어합니다.
피해 판정, 캐릭터 동작, 사운드는 포함하지 않은 독립적인 시각 효과입니다.
원본 영상의 검은 원반과 밝은 테두리를 참고하되 사슬·참격·폭발 단계를 사용하지 않았습니다.

검증: 별도 Unity 6000.3.11f1 프로젝트에서 컴파일, 동일 URP 2D 설정의 단계별 렌더,
씬 프리팹 로드, DOTween 2회 반복, 비활성화 정리, 단발 완료 및 재시작 확인.
기존 테스트 씬의 카메라와 설정은 바이트 비교로 보존 여부를 확인했습니다.
