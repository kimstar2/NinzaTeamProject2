# 기획 스킬 세팅

기획서 스킬을 SkillDataSO로 옮기고 주사위·몬스터·재련에 연결한 것. 수치는 레벨 1 기준 (실제 값 = 수치 × 레벨).

## 폴더

| 폴더 | 내용 |
| --- | --- |
| `Unique/<직업>` | 플레이어 고유 스킬 (Tank / Warrior / Mage / Healer). 일식만 `PSW/GameModule/Skills/SolarEclipse Data` |
| `Boss/Forest`, `Boss/Volcano` | 1스테이지 / 2스테이지 보스 스킬 |
| `Monster/Forest`, `Monster/Volcano` | 1스테이지 / 2스테이지 일반 몬스터 스킬 |
| `Monster/TwilightShaman`, `Monster/WraithReaper` | 1스테이지 / 2스테이지 정예 스킬 |
| `Faces/Unique`, `Faces/Boss`, `Faces/Monster` | 스킬 하나당 주사위 면 1개 |
| `DiceLists` | 6면 주사위. `Player_*`는 PlayerData의 defaultDiceList, 나머지는 EnemyData의 DiceDataList |
| `Forge Grade Up Pool` | 재련 등급 업 결과로 나올 수 있는 면 목록 |

- 아이콘은 **스킬 데이터와 면 둘 다** 넣는다. 전투 주사위는 스킬 아이콘, 가방·재련·보상 카드는 면 아이콘을 쓴다.
- 플레이어 아이콘: `06.Sprite/SkillSpriteSheet` (행: 탱커 → 전사 → 힐러 → 마법사, 행 안은 기획 목록 순서). 단, 추격은 `SkillSpriteSheet_14`.
- 몬스터 아이콘: `06.Sprite/monster_skills_2` (행: 2스테이지 일반 9 → 2스테이지 보스 7 → 1스테이지 정예 6 → 2스테이지 정예 6). 1스테이지는 `06.Sprite/monster_skills_1` (1행 일반 12: 맹독 분사, 독 폭발, 가시 채찍, 뿌리 폭발, 환상적인 꽃가루, 가시 갑옷, 야수의 포효, 위장, 덩굴 속박, 덩굴 장벽, 레이더, 심호흡 / 2행 보스 7: 맹독 폭발, 독성 지대, 비상 식량, 가시 갑주, 거대 덩굴 속박, 원시림의 분노, 야수의 포식 — 그림 기준 순서).

## 등급 / 강함도 / 행운

| 등급 (DiceGrade) | 표시 | 해당 스킬 |
| --- | --- | --- |
| Common | 일반 | 일반 몬스터 스킬 |
| Uncommon | 희귀 | 정예 스킬 |
| Rare | 전설 | 플레이어·보스 고유 스킬 |

- **Strength(강함도)**: 기획서 괄호 숫자. 플레이어에게 보이지 않는 확률 보정용.
- **행운**: 플레이어 주사위를 굴릴 때 면 가중치 `e^(행운 × luckSharpness × 강함도/100)`. 행운 0이면 균등.
  행운 = 위험도 비율 × `luckAtMaxRisk` (PlayerDiceRollManager) + 보너스. 아이템·유물은 `ServiceLocator.Get<ILuckProvider>().AddBonusLuck(값)`. 적 주사위는 균등.

## 스킬 옵션 (SkillDataSO)

| 필드 | 동작 |
| --- | --- |
| Target / Synergy | 대상(적·아군·자신), 시너지(표식 +25% 2회, 보호 -30% 2회, 격려 다음 공격 +35%) |
| Status / StatusDamage / StatusTurns | 독·화상·낙인. 턴이 끝날 때마다 피해 |
| BonusVsStatus / BonusDamage | 해당 상태인 대상에게 추가 피해 |
| MissChance / MissTurns | 맞은 대상의 공격이 확률로 빗나감 |
| StunTurns | 맞은 대상이 공격하지 못함 (1 = 이번 턴, 2 = 다음 턴까지) |
| ReflectRatio / ReflectTurns | 대상이 받은 스킬 피해 중 비율만큼 공격자에게 되돌림 |
| CleanseDebuffs | 대상의 디버프(표식, 지속 피해, 빗나감, 행동 불가) 모두 제거 |
| HealthCost | 시전 시 체력 소모 (1은 남김) |
| ExecuteThreshold | 타격 후 체력 비율이 이하면 즉시 처치 |
| EnemyTargetRule | 몬스터가 쓸 때 대상: Default / Random / LowestHealth |
| suitableTypes | 이 면을 장착할 수 있는 직업. 비우면 모두. 몬스터 사용에는 영향 없음 |
| IsArea | 광역. 대상 진영 전체(적 전체 / 아군 전체)에 적용. 플레이어는 대상을 고르지 않고 바로 연결 |
| InvulnerableTurns | 대상이 그 턴 동안 스킬 공격 피해를 모두 무시 (무력화). 지속 피해는 들어감 |
| HealMaxHealthRatio | 대상 최대 체력의 비율만큼 추가 회복 (재생의 빛 30%). 재련 레벨 1당 +25% |
| TauntTurns | 도발: 그 턴 수 동안 상대의 단일 공격이 대상에게 향함 (압도 2턴) |
| ResistRatio / ResistTurns | 받는 공격 피해 N% 감소 (압도 20%·2턴). 보호와 별개로 곱해짐 |
| WeakenRatio / WeakenTurns | 둔화: 대상이 주는 피해 N% 감소 (서리지대 15%·2턴). 정화로 제거됨 |
| PowerUpRatio / PowerUpTurns | 공격력 증가: 대상이 주는 피해 N% 증가 (야수의 포효 15%, 화염 폭주 25%, 과열 30%, 전투 독려 20%, 모두 2턴) |
| SelfDestruct | 스킬을 쓴 뒤 시전자가 쓰러짐 (자폭) |
| EffectColor | 이 스킬이 건 디버프의 문구·캐릭터 색. 투명이면 종류별 기본색 |
| Strength | 강함도 |

- 광역 스킬: 전투 본능, 일식, 치유의 파동, 전투 독려 / 맹독 폭발, 독성 지대, 원시림의 분노, 화산 폭발, 분화(보스), 대폭발 / 야수의 포효, 덩굴 장벽, 자폭, 황혼 폭발, 초승달 참격. 보스의 2회 행동은 단일 공격에만 적용. 플레이어는 자신 스킬처럼 자기에게 연결되고, 연출은 살아 있는 상대 중 가운데(짝수면 위쪽)를 향한다.
- 떠오르는 문구·디버프 색: `CombatStatusVisual`이 모든 캐릭터·몬스터에 자동으로 붙는다. 폰트는 `AgentEffectsView` 글자 폰트를 쓴다.
- 3회 공격: MeleeStrikeSkill의 `hitWeights`(타격별 배율). 난타는 `Unique/Warrior/Barrage Skill.prefab` (0.15 / 0.15 / 0.7).
- 효과 문구는 스킬 설명에 자동으로 붙는다. 턴 수는 "걸린 턴 + 다음 턴"을 2로 센다.

## 직업

AgentAttackType: Archer 0, Melee 1(전사), Magic 2, Healer 3, Tank 4.
화면 이름: 탱커 / 전사 / 마법사 / 힐러. 기존 면에는 전사 스킬을 복사한 Tank 항목이 들어 있다.

| 직업 | 시작 주사위 6면 |
| --- | --- |
| 탱커 | 무력화, 제압, 압도, 절대 방어, 대지의 분노, 카운터 |
| 전사 | 난타, 추격, 처형, 참격, 분쇄, 전투 본능 |
| 마법사 | 마력 낙인, 감전, 서리지대, 광선, 일식, 속박 |
| 힐러 | 재생의 빛, 생명 흡수, 실명, 전투 독려, 치유의 파동, 성역 |

미구현 고유 스킬: 진통(보호막 제거·회복 감소 필요).

## 재련 (BattleInventory)

기준 면 1개 + 재료 면 2개. 재료 등급을 기준 면 등급과 비교한다.

| 재료 2개 | 결과 | 비용 |
| --- | --- | --- |
| 둘 다 기준보다 낮은 등급 | 레벨 +0.5 (`forgeLevelGain`) | 기본 |
| 하나는 낮고 하나는 같거나 높음 | 레벨 +1 (`mixedLevelGain`) | 기본 |
| 둘 다 같거나 높은 등급 | 한 단계 위 등급 스킬로 변환, Lv.1 | 기본 × 1.35 (`gradeUpCostMultiplier`) |
| 위 조건인데 기준이 전설이거나 올라갈 스킬이 없음 | 레벨 +1 | 기본 |

- 기본 비용 = 20G × 기준 면 레벨. 최대 레벨 3 (등급 업은 레벨과 무관).
- 등급 업 후보: 풀 에셋의 다음 등급 면 중 기준 면을 쓸 수 있던 직업을 모두 유지하는 스킬 → 없으면 한 직업이라도 겹치는 스킬.
- 재료가 자기 등급 안에서 강함도가 높을수록(기준보다 높은 등급 재료는 최고로 취급) 강함도 높은 스킬이 잘 나온다. 폭은 `gradeUpSpread`.
- 재련 안내: `BattleAssist/Resources/ForgeTutorial` (전투 도움말 프리팹 복제). UpgradeManager가 재련 창 안에 생성한다. 문구는 프리팹의 pages에서 수정.
- 새 면을 만들면 풀 에셋에도 넣어야 한다. 힐러 전용 일반 스킬(심호흡)은 힐러용 희귀 스킬이 없어 레벨 +1이 된다.

## 아직 표현 못 하는 것 (코드 필요)

- 2명 공격(뿌리 폭발, 용암 분출, 폭발 포자, 낫의 잔상, 거대 덩굴 속박, 불길한 속삭임) → 1명
- 보호막, 방어력·공격력 % 증감, 몬스터 전체 버프, 크기 변화, 디버프 면역, 회복량 감소, 다음 턴 발동(폭발 표식·분화), 자폭의 자기 사망(체력 1 남음)
- 방어·버프는 기존 시너지로 대체: 보호(받는 공격 2회 -30%), 표식(받는 공격 2회 +25%), 격려(다음 공격 +35%)
