# 기획 스킬 세팅

기획서의 스킬을 현재 스킬 시스템(SkillDataSO + 기존 Skill.prefab)으로 옮긴 것.
새 실행 프리팹은 만들지 않고 기존 프리팹을 재사용했다. 값은 레벨 1 기준.

- `Unique/` : 플레이어 파티 고유 스킬 (탱커 / 전사 / 마법사 / 힐러)
- `Monster/` : 몬스터 스킬. 괄호 숫자는 SkillDataSO의 **Strength(강함도)** 에 넣었다.
- 고유 스킬은 기획서에 강함도가 없어서 0으로 두었다.

## 현재 시스템으로 표현 가능한 것

| 항목 | 값 |
| --- | --- |
| 대상 | 적 1명 / 아군 1명 / 자신 (광역, 랜덤 대상 없음) |
| 수치 | 피해, 회복, 흡혈 비율 |
| 시너지 | 표식(받는 공격 2회 피해 +25%), 보호(받는 공격 2회 피해 -30%), 격려(다음 공격·회복 +35%) |
| 조건 | 대상 체력 35% 이하 1.6배 등 |

적 AI 대상: 적 대상 = 자신을 공격한 플레이어, 아군 대상 = 체력 비율이 가장 낮은 몬스터, 자신 = 자신.

## 만들지 않은 스킬

핵심 효과가 상태이상이라 현재 시스템으로 표현할 방법이 없음.
제압(공격 불가), 카운터(반사·방어 중첩), 속박(공격 불가), 실명(빗나감), 진통(보호막 제거·회복 감소), 성역(디버프 면역).

일식은 이미 `SolarEclipse/Solar Eclipse Skill.asset`이 있어서 만들지 않았다.
