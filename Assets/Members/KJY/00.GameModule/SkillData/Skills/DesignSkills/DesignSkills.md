# 기획 스킬 세팅

기획서 스킬을 SkillDataSO로 옮기고 주사위·몬스터·재련에 연결한 것. 수치는 레벨 1 기준 (실제 값 = 수치 × 레벨).

## 폴더

| 폴더 | 내용 |
| --- | --- |
| `Unique/<직업>` | 플레이어 고유 스킬 (Tank / Warrior / Mage / Healer). 일식만 `PSW/GameModule/Skills/SolarEclipse Data` |
| `Boss/Forest`, `Boss/Volcano` | 1스테이지 / 2스테이지 보스 스킬 |
| `Monster/Forest`, `Monster/Volcano` | 1스테이지 / 2스테이지 일반 몬스터 스킬 |
| `Monster/TwilightShaman`, `Monster/WraithReaper` | 1스테이지 / 2스테이지 정예 스킬 |
| `Faces/Unique`, `Faces/Boss`, `Faces/Monster` | 스킬 하나당 주사위 면 1개 |
| `DiceLists` | 6면 주사위. `Player_*`는 PlayerData의 defaultDiceList, 나머지는 EnemyData의 DiceDataList |
| `Forge Grade Up Pool` | 재련 등급 업 결과로 나올 수 있는 면 목록 |

- 아이콘은 **스킬 데이터와 면 둘 다** 넣는다. 전투 주사위는 스킬 아이콘, 가방·재련·보상 카드는 면 아이콘을 쓴다.
- 플레이어 아이콘: `06.Sprite/SkillSpriteSheet` (행: 탱커 → 전사 → 힐러 → 마법사, 행 안은 기획 목록 순서). 단, 추격은 `SkillSpriteSheet_14`.
- 몬스터 아이콘: `06.Sprite/monster_skills_2` (행: 2스테이지 일반 9 → 2스테이지 보스 7 → 1스테이지 정예 6 → 2스테이지 정예 6). 1스테이지는 `06.Sprite/monster_skills_1` (배경이 연한 올리브색 `#9DB374`라 어두운 UI에서 그림 아래가 흰 띠처럼 보일 수 있음) (1행 일반 12: 맹독 분사, 독 폭발, 가시 채찍, 뿌리 폭발, 환상적인 꽃가루, 가시 갑옷, 야수의 포효, 위장, 덩굴 속박, 덩굴 장벽, 레이더, 심호흡 / 2행 보스 7: 원시림의 분노, 독성 지대, 비상 식량, 가시 갑주, 거대 덩굴 속박, 맹독 폭발, 야수의 포식 — 그림 기준 순서).

## 등급 / 강함도 / 행운

| 등급 (DiceGrade) | 표시 | 해당 스킬 |
| --- | --- | --- |
| Common | 일반 | 일반 몬스터 스킬 |
| Uncommon | 희귀 | 정예 스킬 |
| Rare | 전설 | 플레이어·보스 고유 스킬 |

- **Strength(강함도)**: 기획서 괄호 숫자. 플레이어에게 보이지 않는 확률 보정용.
- **행운**: 플레이어 주사위를 굴릴 때 면 가중치 `e^(행운 × luckSharpness × 강함도/100)`. 행운 0이면 균등.
  행운 = 위험도 비율 × `luckAtMaxRisk` (PlayerDiceRollManager) + 보너스. 아이템·유물은 `ServiceLocator.Get<ILuckProvider>().AddBonusLuck(값)`. 적 주사위는 균등.

## 스킬 옵션 (SkillDataSO)

| 필드 | 동작 |
| --- | --- |
| Target / Synergy | 대상(적·아군·자신), 시너지(표식 받는 공격 2회 +25%, 표식 소모 +50%, 보호 받는 공격 2회 -30%, 격려 다음 공격·회복 +35%) |
| Status / StatusDamage / StatusTurns | 독·화상·낙인. 턴이 끝날 때마다 피해 (보호 무시) |
| BonusVsStatus / BonusDamage | 해당 상태인 대상에게 추가 피해 |
| MissChance / MissTurns | 맞은 대상의 공격이 확률로 빗나감 |
| StunTurns | 맞은 대상이 공격하지 못함 (1 = 이번 턴, 2 = 다음 턴까지). 보스는 턴마다 공격 1회만 막힘 |
| ReflectRatio / ReflectTurns | 대상이 받은 스킬 피해 중 비율만큼 공격자에게 되돌림 |
| CleanseDebuffs | 대상의 디버프(표식, 지속 피해, 빗나감, 행동 불가, 둔화) 모두 제거 |
| HealthCost | 시전 시 체력 소모 (1은 남김) |
| ExecuteThreshold | 타격 후 체력 비율이 이하면 즉시 처치 (보호 무시) |
| EnemyTargetRule | 몬스터가 쓸 때 대상: Default = [보복] / Random = [무작위] / LowestHealth = [낮은 체력] |
| suitableTypes | 이 면을 장착할 수 있는 직업. 비우면 모두. 몬스터 사용에는 영향 없음 |
| IsArea | 광역. 대상 진영 전체(적 전체 / 아군 전체)에 적용. 플레이어는 대상을 고르지 않고 바로 연결 |
| InvulnerableTurns | 무적: 그 턴 동안 스킬 공격 피해를 모두 무시. 지속 피해는 들어감 |
| HealMaxHealthRatio | 대상 최대 체력의 비율만큼 추가 회복. 재련 레벨 1당 +25% |
| TauntTurns | 도발: 그 턴 수 동안 상대의 단일 공격이 대상에게 향함 |
| ResistRatio / ResistTurns | 피해 감소: 받는 공격 피해 N% 감소. 보호와 별개로 곱해짐 |
| WeakenRatio / WeakenTurns | 둔화: 대상이 주는 피해 N% 감소 |
| PowerUpRatio / PowerUpTurns | 공격력 증가: 대상이 주는 피해 N% 증가 |
| SelfDestruct | 스킬을 쓴 뒤 시전자가 쓰러짐 |
| NoCastMotion | 시전 모션 없이 바로 효과 적용 (방어·보호 스킬) |
| EffectColor | 이 스킬이 건 디버프의 문구·캐릭터 색. 투명이면 종류별 기본색 |
| Strength | 강함도 |

- 대상 표시: 플레이어 [적 선택]/[적 전체]/[아군 선택]/[아군 전체]/[자신], 몬스터 [보복]/[무작위]/[낮은 체력]/[전체]/[아군 전체]/[아군 낮은 체력]/[자신].
- 광역: 보스의 2회 행동은 단일 공격에만 적용. 연출은 살아 있는 상대 중 가운데(짝수면 위쪽)를 향한다.
- 3회 공격: MeleeStrikeSkill의 `hitWeights`(타격별 배율). 난타는 `Unique/Warrior/Barrage Skill.prefab` (0.15 / 0.15 / 0.7).
- 효과 문구는 스킬 설명에 자동으로 붙는다. 턴 수는 "걸린 턴 + 다음 턴"을 2로 센다.

화면 이름: 탱커 / 전사 / 마법사 / 힐러. 기존 면에는 전사 스킬을 복사한 Tank 항목이 들어 있다.

## 재련 (BattleInventory)

기준 면 1개 + 재료 면 2개. 재료 등급을 기준 면 등급과 비교한다.

| 재료 2개 | 결과 | 비용 |
| --- | --- | --- |
| 둘 다 기준보다 낮은 등급 | 레벨 +0.5 (`forgeLevelGain`) | 기본 |
| 하나는 낮고 하나는 같거나 높음 | 레벨 +1 (`mixedLevelGain`) | 기본 |
| 둘 다 같거나 높은 등급 | 한 단계 위 등급 스킬로 변환, Lv.1 | 기본 × 1.35 (`gradeUpCostMultiplier`) |
| 위 조건인데 기준이 전설이거나 올라갈 스킬이 없음 | 레벨 +1 | 기본 |

- 기본 비용 = 20G × 기준 면 레벨. 최대 레벨 3 (등급 업은 레벨과 무관).
- 등급 업 후보: 풀 에셋의 다음 등급 면 중 기준 면을 쓸 수 있던 직업을 모두 유지하는 스킬 → 없으면 한 직업이라도 겹치는 스킬.
- 재료가 자기 등급 안에서 강함도가 높을수록(기준보다 높은 등급 재료는 최고로 취급) 강함도 높은 스킬이 잘 나온다. 폭은 `gradeUpSpread`.
- 재련 안내: `00.GameModule/BattleAssist/ForgeTutorial.prefab` (전투 도움말 프리팹 복제). RestScene의 UpgradeManager `tutorialPrefab`에 연결. 문구는 프리팹의 pages에서 수정.
- 새 면을 만들면 풀 에셋에도 넣어야 한다. 힐러 전용 일반 스킬(심호흡)은 힐러용 희귀 스킬이 없어 레벨 +1이 된다.

## 연출

| 스킬 | 상태 |
| --- | --- |
| 일식 | PSW 전용 연출. 속도는 `SolarEclipse.durationScale` (0.5 = 약 3.3초) |
| 전투 본능 | PSW 전용 연출(일부). 거대 검·3회 베기·화면 금 없음 |
| 대지의 분노 | `Skills/EarthFury` 전용: 점프 후 내려찍기 + 지진처럼 화면 흔들림 |
| 치유의 파동 | `Skills/HealingWave` 전용: 발밑에서 초록 파동 3겹 후 아군 전체 회복 |
| 방어·보호 스킬 11개 | NoCastMotion: 모션 없이 즉시 적용 |
| 나머지 | 공용 연출 프리팹 재사용 (HolyHeal, HeavyStrike 등) |

- 애니메이터: `BaseAgentCon` (Idle / Skill01 / Skill02 / Hurt / Death). 캐릭터마다 Override Controller로 클립 교체. Hurt는 재생하지 않음.

## 주사위 도감

- `Resources/DiceCatalog.asset`: 도감 목록(Faces, 95개 = 기획 스킬 71 + 이벤트 보상 24)과 처음부터 해금된 기본 스킬(StarterFaces, 24개).
- 획득 기록: `DiceCatalogProgress` (PlayerPrefs). 인벤토리에 들어온 면, 재련 등급 상승 결과, 전투 시작 시 장착 면이 기록된다.
- 새 스킬을 만들면 Faces에도 넣어야 도감에 나온다. 기록 초기화: 메뉴 KJY → 주사위 도감 기록 초기화.

## 밸런스 기준

목표: 일반 전투는 파티 체력 20~40%, 정예는 절반 가까이, 보스는 쓰러지기 직전까지 깎이는 긴장감. 전투 사이 체력은 이어지고 회복은 힐러·휴식(50%)뿐이다.

**적 실제 수치 = 스킬 수치 × 적 레벨**

- 적 레벨 = (1 + 위험도/100 × `maxRiskPenalty` 0.9) × 스테이지 DicePower × (정예·보스 1.1)
- 다시 굴릴수록 위험도가 올라 적이 최대 1.9배까지 세진다. 대신 행운이 올라 좋은 면이 잘 나온다.

| 스테이지 설정 | 초반 → 후반 | 파일 |
| --- | --- | --- |
| 적 체력 배율 (healthMultiplier) | 1.3 → 1.6 | `EnemyData/Stage 1`, `Stage 2` |
| 적 주사위 위력 (dicePower) | 1.15 → 1.3 | `EnemyData/Stage 1`, `Stage 2` |
| 다시 굴리기 페널티 (maxRiskPenalty) | 0.9 | `BattleData/TestBattle data` |

정예(300)·보스(500)는 고정 체력이라 체력 배율의 영향을 받지 않고, 위력은 스테이지 후반 값 × 1.1을 쓴다.

- 플레이어 고유 스킬은 강함도가 높을수록 강하게: 전사는 단일 딜, 마법사는 광역·디버프, 탱커는 방어, 힐러는 회복·방해.
- 방어 스킬 역할 분리: 보호(받는 공격 2회 -30%) / 보호+반사(가시 갑옷·가시 갑주) / 피해 감소(위장·용암 갑옷·용암 갑주) / 보호+정화(주술 결계).
- 효과만 있던 스킬에 보조 효과 추가: 환상적인 꽃가루(빗나감), 상처(낙인), 불길한 속삭임(둔화), 죽음의 표식(낙인), 폭발 표식(화상), 속박(피해 10).
- 플레이어 고유 스킬은 Lv.1을 초반 기준으로 약하게 두고, 성장은 재련 레벨(수치 × 레벨)로 한다.
- 난이도 조절은 스킬 수치보다 위 스테이지 배율 3개로 먼저 한다.
